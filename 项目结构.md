## 项目根目录 `IntstrutMe1.0/`

**配置文件**

| 文件                 | 作用                                             |
| ------------------ | ---------------------------------------------- |
| `package.json`     | 扩展清单：注册侧边栏视图、命令、脚本（compile/watch/mcp:start）、依赖 |
| `tsconfig.json`    | TypeScript 编译配置（Node16 模块解析）                   |
| `.gitignore`       | Git 忽略：node_modules/out/.instruct-me/.cursor 等 |
| `.vscodeignore`    | 打包 VSIX 时排除的文件                                 |
| `mcp.example.json` | MCP 客户端接入模板（给使用者参考，不含真实 Key）                   |
| `.vscode/`         | 开发调试配置：launch.json（F5 启动）、tasks.json（编译任务）     |
| `.cursor/`         | Cursor 的 MCP 配置（含占位 API Key，已 gitignore）       |

**源码目录 `src/`**

| 文件                         | 作用                                                                 |
| -------------------------- | ------------------------------------------------------------------ |
| `extension.ts`             | **扩展入口**：注册侧边栏 webview、MCP 客户端、Session 管理、LLM 调用、所有消息路由            |
| `config.ts`                | **多模型配置管理**：多个 profile（OpenAI/DeepSeek/Ollama/自定义）存 SecretStorage  |
| `session.ts`               | **复盘记录持久化**：按项目目录保存 `.instruct-me/sessions.json`                   |
| `llm/provider.ts`          | **LLM 网关**：OpenAI 兼容调用（chat/流式）、失败重试、多服务商预设                        |
| `mcp/server.ts`            | **MCP Server**：暴露 `analyze_project`（项目扫描）+ `generate_review`（生成问题） |
| `mcp/client.ts`            | **MCP 客户端**：扩展内启动 server 子进程，JSON-RPC 通信                           |
| `mcp/llm.ts`               | MCP server 内的 LLM 调用封装（模板回退 + LLM）                                 |
| `prompts/reviewPrompts.ts` | **Prompt 引擎**：L1/L2/L3 三级系统提示词 + few-shot 示例                       |
| `webview/sidebar.ts`       | Webview 前端源码（TS 版，可单独打包参考）                                         |

**静态资源 `media/`**

| 文件            | 作用                                            |
| ------------- | --------------------------------------------- |
| `sidebar.css` | Webview 样式（全用 VS Code 主题变量，自适应深浅色）            |
| `sidebar.js`  | **Webview 前端逻辑**：问题列表渲染、折叠/展开、关键词高亮、追问聊天、配置界面 |
| `icon.png`    | 侧边栏活动栏图标                                      |

**测试 `test/`**

| 文件               | 作用                              |
| ---------------- | ------------------------------- |
| `test_levels.js` | 验证 L1/L2/L3 生成效果                |
| `test_client.js` | 端到端验证 MCP 客户端调用                 |
| `test_llm.js`    | 验证 LLM chat/流式（需设 TEST_API_KEY） |
| `test_prompt.js` | 查看组装后的 prompt 格式                |

**编译产物 `out/`**（gitignore，由 `npm run compile` 生成，运行时实际加载）

---

**数据流**：侧边栏 webview（media/）→ 扩展进程（extension.ts）→ MCP 子进程（mcp/server.ts）扫项目 / LLM 网关（llm/provider.ts）生成问题 → 复盘记录存 session.ts → `.instruct-me/sessions.json`
